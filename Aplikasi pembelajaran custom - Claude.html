Claude merespons: File JSX Ibu sudah masuk ke GitHub.

Membuat 4 file, membaca 3 halaman

File JSX Ibu sudah masuk ke GitHub. Tahap berikutnya adalah membungkusnya supaya bisa dibuka sebagai link. Saya sudah menyiapkan empat file pendukung: index.html, main.jsx, package.json, dan vite.config.js. File-file itu ada di panel file di samping chat ini. Semuanya sengaja diletakkan sejajar tanpa folder, supaya gampang diunggah lewat browser.

Langkahnya:

  1. Unduh keempat file itu ke komputer Ibu.
  2. Di halaman repo, klik Add file → Upload files, seret keempat file itu bersama-sama, lalu klik Commit changes. File JSX yang sudah ada tidak perlu diubah atau diunggah ulang.
  3. Buka vercel.com dan login dengan Continue with GitHub.
  4. Klik Add New → Project, pilih repo Turunan-Eksponensial-dan-Fungsi-Logaritma, lalu klik Import.
  5. Di halaman pengaturan, biarkan semuanya seperti bawaan. Vercel akan mengenali proyeknya sebagai Vite. Klik Deploy.
  6. Tunggu sekitar satu menit. Setelah selesai, Vercel menampilkan alamat seperti nama-proyek.vercel.app. Itulah link yang dibagikan ke mahasiswa.

Ada satu hal yang perlu diperiksa setelah link jadi. Dari yang bisa saya baca, kode Ibu memakai window.claude.complete sebagai cadangan kalau mahasiswa tidak mengisi API key sendiri. Fungsi itu hanya ada di dalam lingkungan Claude, jadi di link Vercel tutor AI-nya hanya jalan kalau mahasiswa memasukkan API key sendiri. Itu sesuai dengan keinginan Ibu agar biaya ditanggung mahasiswa, tapi pastikan ada kolom isian key yang jelas dan tulisan petunjuknya.

Saya juga belum bisa memastikan file JSX itu punya export default. Kalau halaman putih atau Vercel menampilkan error saat build, kirim tangkapan layarnya ke sini dan saya perbaiki.
